# power-automate

- **Cloud flows** — deterministic orchestration invoked by the Sentinel Orchestrator: approvals,
  Dataverse writes, hand-offs to execution runtimes. All runs are logged & reversible.
- **Desktop flows (Power Automate Desktop)** — Windows/desktop RPA for legacy systems.

Connectors constrained by DLP (business vs. non-business); consumer AI blocked. Auth via
Managed Identity / service principal; secrets in Key Vault.
